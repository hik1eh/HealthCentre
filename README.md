# HealthCentre

HealthCentre - веб-приложение для стоматологической клиники на Django. Система объединяет публичный каталог услуг, запись пациентов на прием, личные кабинеты врача и пациента, медицинские записи, счета, оплату через Stripe и административную панель.

## Возможности

- Регистрация и авторизация пользователей по email.
- Разделение пользователей по ролям: врач и пациент.
- Публичный каталог стоматологических услуг.
- Просмотр карточки услуги и доступных врачей.
- Запись пациента на прием к выбранному врачу.
- Автоматическое создание счета после записи.
- Оплата счета через Stripe Checkout.
- Личный кабинет пациента:
  - список записей на прием;
  - просмотр деталей приема;
  - история платежей;
  - уведомления;
  - редактирование профиля.
- Личный кабинет врача:
  - список назначенных приемов;
  - просмотр деталей приема;
  - управление статусом приема;
  - добавление медицинских записей;
  - добавление лабораторных тестов;
  - добавление назначений и рецептов;
  - просмотр оплаченных счетов;
  - уведомления;
  - редактирование профиля.
- Административная панель на базе Django Admin и django-jazzmin.

Проект разделен на несколько Django-приложений:

```text

├── authuser/      # регистрация, вход, выход, кастомная модель пользователя

├── static/        # статические файлы
├── media/         # загружаемые изображения и файлы
└── manage.py
```

## Основные модели

### User

Кастомная модель пользователя наследуется от `AbstractUser`. Для входа используется email, а поле `user_type` определяет роль пользователя в системе: `Doctor` или `Pacient`.

### Doctor

Профиль врача содержит ФИО, фотографию, телефон, город, специализацию, квалификацию, стаж, биографию и ближайшую доступную дату приема.

### Pacient

Профиль пациента хранит ФИО, email, телефон, адрес, пол, группу крови, дату рождения и изображение профиля.

### Service

Модель услуги содержит название, описание, стоимость, изображение и список врачей, которые оказывают эту услугу.

### Appointment

Модель записи на прием связывает пациента, врача и услугу. Для каждой записи хранится дата приема, жалобы, симптомы, уникальный короткий идентификатор и статус.

Доступные статусы:

- Запланировано
- Выполнено
- Рассматривается
- Отменено

### Billing

Модель счета создается для записи на прием и хранит сумму услуги, налог, итоговую стоимость, статус оплаты, дату и уникальный номер счета.

### MedicalRecord, LabTest, Prescription

Эти модели используются врачом для ведения медицинской информации по конкретному приему: диагнозы, лечение, лабораторные тесты и назначения.

### Notification

Отдельные модели уведомлений используются для врача и пациента. Уведомления связаны с приемом и позволяют отслеживать новые или измененные события.

## Основные маршруты

```text
/                         # главная страница со списком услуг
/service/<id>/            # страница услуги
/book-appointment/<service_id>/<doctor_id>/  # запись на прием
/checkout/<billing_id>/   # страница оплаты
/payment_status/<billing_id>/ # результат оплаты

/authuser/sign-up/        # регистрация
/authuser/sign-in/        # вход
/authuser/sign-out/       # выход

/doctor/                  # кабинет врача
/doctor/appointments/     # приемы врача
/doctor/payments/         # платежи врача
/doctor/notifications/    # уведомления врача
/doctor/profile/          # профиль врача

/pacient/                 # кабинет пациента
/pacient/appointments/    # приемы пациента
/pacient/payments/        # платежи пациента
/pacient/notifications/   # уведомления пациента
/pacient/profile/         # профиль пациента

/admin/                   # административная панель
```

## Установка и запуск

### 1. Клонировать проект

```bash
git clone <repository-url>
cd HealthCentre
```

### 2. Создать виртуальное окружение

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

Linux/macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirments.txt
```

### 4. Создать файл окружения

В корне проекта нужно создать файл `.env` и добавить Stripe-ключи:

```env
STRIPE_PUBLIC_KEY=pk_test_...
STRIPE_SECRET_KEY=sk_test_...
```

### 5. Применить миграции

```bash
python manage.py migrate
```

### 6. Создать администратора

```bash
python manage.py createsuperuser
```

### 7. Запустить сервер разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```

Административная панель:

```text
http://127.0.0.1:8000/admin/
```

## Настройки окружения

Проект использует `environs` для чтения переменных окружения из `.env`.

Обязательные переменные:

```env
STRIPE_PUBLIC_KEY=pk_test_...
STRIPE_SECRET_KEY=sk_test_...
```

Для production-окружения также рекомендуется вынести в переменные окружения:

```env
SECRET_KEY=...
DEBUG=False
ALLOWED_HOSTS=example.com,www.example.com
```

## Платежный сценарий

1. Пациент выбирает услугу и врача.
2. Система создает запись на прием.
3. Для записи автоматически создается счет.
4. Пациент переходит на страницу оплаты.
5. Stripe Checkout создает платежную сессию.
6. После успешной оплаты счет получает статус "Оплачено".
7. Запись получает статус "Выполнено".
8. Врач и пациент получают уведомления.
