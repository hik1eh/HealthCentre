HealtCentre – веб‑сервис стоматологии

HealtCentre – это полнофункциональный веб‑сервис для стоматологической клиники, разработанный на Django 5.
Сайт позволяет пациентам записываться на приём, оплачивать услуги и отслеживать историю посещений, а врачам — управлять записями, вести медицинские записи и видеть статистику по оплатам.
Проект использует собственную модель пользователя с разделением ролей «Доктор» и «Пациент», поддерживает уведомления и интегрирован с платёжной системой Stripe.

Основные возможности:

Авторизация и регистрация. Проект включает собственную модель пользователя, наследующую AbstractUser.
В модели User email используется в качестве имени для входа; пользователь хранит тип (Doctor или Pacient), что позволяет разграничить интерфейсы.
Формы регистрации и входа размещены в приложении authuser и обеспечивают простую регистрацию нового врача или пациента.

Профили врачей и пациентов.

Модель Doctor содержит данные о специалисте – фотографию, ФИО, телефон, город, специализацию, квалификацию, стаж и дату ближайшего приёма.

Модель Pacient хранит информацию о пациенте: имя, email, телефон, адрес, пол, группу крови и дату рождения.

Услуги.
Справочник услуг (Service) содержит название, описание, стоимость и изображение услуги; к услуге привязываются доступные врачи.
На главной странице выводятся все доступные услуги.
Пациент может открыть карточку услуги для просмотра подробностей.

Запись на приём.
Пациент выбирает услугу и врача, заполняет контактные данные и симптомы; система создаёт новую запись в модели Appointment и автоматически формирует счёт (Billing) с расчётом стоимости и налогов.
Статус приёма может быть «Запланировано», «Выполнено», «Рассматривается» или «Отменено».
Врач и пациент могут активировать, отменять или завершать приёмы через личный кабинет.

Медицинские записи, лабораторные тесты и назначения.
Врач может добавлять к приёму медицинские записи, лабораторные тесты и назначения.
Создание и редактирование записей реализовано в doctor/views.py, а пациенты могут просматривать эти данные на странице подробностей приёма.

Выставление счетов и платежи.
Модель Billing содержит сумму услуги, налог, итоговую сумму, дату и статус платежа (оплачен/не оплачен).
На стадии записи формируется счёт; пользователь перенаправляется на страницу оплаты.
Оплата реализована через Stripe Checkout: сессия создаётся в представлении stripe_payment и принимает e‑mail пациента, сумму и описание платежа.
После успешной оплаты статус счёта автоматически меняется на «Оплачено», а приёму присваивается статус «Выполнено»; система отправляет уведомления врачу и пациенту.

Уведомления.
Каждому врачу и пациенту соответствуют модели Notification, в которых фиксируются события («Новая запись», «Отмена записи» и т.д.).
В интерфейсе можно отметить уведомление как прочитанное, чтобы убрать его из списка.

Личный кабинет врача.
После входа врач видит панель с назначенными приёмами, уведомлениями и возможностью перейти к детальной информации.
Врач может отменить, активировать или завершить приём, добавить или редактировать медицинскую запись, назначить лабораторный тест и назначить препараты.
Также доступен раздел «Платежи» для просмотра всех оплаченных записей и раздел «Профиль» для обновления личных данных.

Личный кабинет пациента.
Пациент видит список всех своих приёмов, уведомления, суммарные расходы и может просмотреть подробности каждого приёма.
Пациент может отменять, активировать или завершать приёмы, просматривать счета и оплачивать их.
Страница профиля позволяет обновить личные данные.

Административная панель.
Проект использует плагин django‑jazzmin
 для современного интерфейса административной панели.
Модели Service, Appointment, MedicalRecord, LabTest, Prescription, Billing, Doctor, Pacient и Notification зарегистрированы в админке с удобными списками и фильтрами.

Локализация и часовой пояс.
Приложение настроено на русский язык (LANGUAGE_CODE = 'ru') и часовой пояс Москвы (TIME_ZONE = 'Europe/Moscow').
Все интерфейсы и уведомления представлены на русском языке.

Установка

Следующие инструкции предполагают наличие Python 3.10+ и pip. Для изоляции зависимостей рекомендуется использовать виртуальное окружение.

Клонируйте репозиторий:

git clone https://github.com/hik1eh/HealthCentre.git
cd HealthCentre


Создайте и активируйте виртуальное окружение:

python3 -m venv venv
source venv/bin/activate


Установите зависимости. В проекте нет requirements.txt, однако из исходного кода видно, что используются следующие пакеты:

pip install django==5.2 shortuuid environs stripe django-jazzmin


При необходимости добавьте и другие библиотеки, если вы расширите функциональность.

Создайте файл .env в корне проекта и определите ключи Stripe и другие параметры окружения:

STRIPE_PUBLIC_KEY=pk_test_...  # публичный ключ Stripe
STRIPE_SECRET_KEY=sk_test_...  # секретный ключ Stripe


Выполните миграции и создайте суперпользователя:

python manage.py migrate
python manage.py createsuperuser


Запустите сервер разработки:

python manage.py runserver


Теперь приложение доступно по адресу http://127.0.0.1:8000/.
Чтобы войти в административную панель, перейдите по /admin/ и используйте данные суперпользователя.

Использование

Главная страница (/) показывает список доступных стоматологических услуг.
Нажмите на услугу, чтобы посмотреть описание и список врачей.
Выберите врача и нажмите «Записаться», чтобы перейти к форме записи.

Регистрация и вход располагаются по адресам /authuser/sign-up/ и /authuser/sign-in/.
При регистрации выберите тип аккаунта («Доктор» или «Пациент»). После входа вы будете перенаправлены в соответствующий личный кабинет.

Личный кабинет пациента (/pacient/):
позволяет просматривать список записей, отменять или подтверждать визиты;
показывает историю платежей и сумму потраченных средств;
уведомляет о новых и отменённых записях;
содержит раздел профиля для редактирования данных.

Личный кабинет врача (/doctor/):
отображает назначенные пациентам приёмы;
предоставляет доступ к медицинским записям, лабораторным тестам и назначениям;
позволяет изменять статус приёма;
показывает оплаченные счета;
содержит раздел профиля для изменения личной информации и даты следующего приёма.

Платежи.
При создании записи система рассчитывает стоимость услуги и создаёт счёт.
Переход на оплату происходит через Stripe Checkout; после успешной оплаты статус обновляется автоматически, а у врача и пациента появляются уведомления.
Все счета можно увидеть в разделах «Платежи» в кабинетах врача и пациента.

Структура проекта
HealthCentre/
├── authuser/      # регистрация, вход, собственная модель пользователя
├── base/          # ядро домена: услуги, записи, счета, платежи, шаблоны главной части
├── doctor/        # функции личного кабинета врача: записи, медкарты, тесты, назначения, профиль, уведомления
├── pacient/       # функции личного кабинета пациента: записи, платежи, профиль, уведомления
├── healtcentre/   # файлы конфигурации Django: settings, urls, wsgi
├── templates/     # HTML‑шаблоны, разбитые по приложениям
├── static/        # статические файлы (CSS, JS, изображения)
├── media/         # загружаемые пользователями файлы
└── manage.py      # точка входа Django

Переменные окружения

Проект использует файл .env и библиотеку environs для чтения конфигурации. Основные параметры:

STRIPE_PUBLIC_KEY и STRIPE_SECRET_KEY — ключи для Stripe, используемые в платёжной системе.

SECRET_KEY — секретный ключ Django (уже задан в settings.py, но рекомендуется перенести его в .env для production).
